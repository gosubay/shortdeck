What was actually solved

A true GTO solve of 50-ante deep heads-up poker is not possible on a PC — it is a problem the size of a national lab. What this is instead is an abstracted equilibrium: the game is simplified in two specific, disclosed ways, that simplified game is solved properly, and real hands are mapped onto it.

Preflop: nothing is simplified

All 630 combinations collapse to 81 strategically identical starting hands, because before a board exists the four suits are interchangeable. That collapse is exact, so preflop is solved with no card abstraction at all.

Postflop: hands are bucketed

Similar hands are grouped. Grouping is potential-aware: two hands only share a bucket if they have a similar spread of outcomes across future cards, not merely the same equity today.

Bet sizes are restricted

Preflop: limp, min-raise, 50% pot, 100% pot, jam. Postflop: 25%, 50%, 100%, 150% pot, jam. Max 4 bets per street.

Nine stack depths

10, 15, 20, 30, 40, 50, 65, 80 and 100 antes, solved separately. The top-up and rathole rules keep every real stack inside that range.

Why bucketing is not optional

People ask why this is not done like PioSOLVER, which uses every combination with no grouping at all. The answer is storage. Pio solves one flop against one pair of ranges. A bot has to know every board. Card-perfect postflop play for a single stack depth works out at roughly:

573 flop classes × ~100,000 decision points × 630 combos ≈ 140 GB

Per stack depth. Your browser is not downloading that. Bucketing brings it to tens of megabytes, and that is the entire reason it exists.

How honest is the result?

Strong, and principled, and beatable by an expert who finds the seams between buckets. It is labelled an approximation everywhere in this app because that is what it is. What it is not is a set of hand-written rules pretending to be a solver.

Run the solver yourself

The solver source lives in solver/ in this repo. It is written in Rust for speed. You need it only if you want to re-run or change the solve — playing the bot needs nothing installed.

  1. Install Rust once (Windows PowerShell):
    winget install Rustlang.Rustup
    then close and reopen PowerShell.
  2. Go to the solver folder:
    cd C:\Claude\Code\shortdeck\solver
  3. Build and run:
    cargo run --release
  4. It prints progress and writes ..\data\strategy.json when done. Commit and push that file and the website picks it up.

The run is long by design. Leave it going; it saves checkpoints as it goes, so stopping it does not lose the work.
